# UI — Style Reference & PWA Redesign Guidelines
> Clinical blueprint on frosted paper, adapted for Coach Amar PWA (Blue & White palette)

**Theme & Brand Color Rule (CRITICAL):**
- **Preserve Brand Colors:** Blue (primary / accent) and White (clean background / cards / text contrast). Do NOT switch away from the blue and white color identity.
- **Design Language:** Modern, clean, minimal, tight geometric typography (Geist / Inter), pill buttons (18px radius), card containers (24px radius), subtle hairlines, and smooth micro-interactions.

---

## Tokens — Colors (Adapted for Blue & White identity)

| Name | Role |
|------|------|
| Primary Blue | Brand accent, primary CTAs, active indicators, highlights |
| Pure White / Paper | Clean card surfaces, high-contrast foreground text, crisp accents |
| Canvas & Surfaces | Crisp clean dark/light backgrounds, frosted paper layers |
| Hairline | Subtle borders, card edges, input outlines |

---

## Tokens — Typography

- **Font:** Geist / Inter
- **Display:** Tight tracking (`-0.05em`), confident engineered headline feel.
- **Body & Captions:** 14px body, 12px captions.

---

## Component Specifications

### Buttons
- **Pill Geometry:** 18px border radius.
- **Primary:** High-emphasis action, full pill shape, clean typography.
- **Secondary / Ghost:** Soft fill, 18px radius, matching dimensions for visual parity.

### Cards & Containers
- **Border Radius:** 24px for cards and containers.
- **Border:** 1px hairline border.
- **Shadow:** Whisper-quiet subtle elevation.

### Badges & Inputs
- **Border Radius:** 18px (pill).

---

## PWA Flow Architecture

1. **Welcome Screen:**
   - Clean, minimalist aesthetic (matching pushr layout).
   - "welcome to ..." / greeting headline with tight tracking.
   - Concise value proposition.
   - Primary pill button: "let's go".

2. **Complete / Login Screen:**
   - Prompt user to complete profile / log in via Google / Gmail.

3. **Client Dashboard:**
   - Redesigned with 24px cards, 18px pill actions, clean stats, and blue & white accents.
